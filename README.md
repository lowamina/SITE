# Code.lowa — Portfolio Site

Personal portfolio and freelance site for Lowamina Pigera (Code.lowa).

## Structure
```
codelowa-site/
├── index.html            # Page markup
├── css/style.css         # All styles (light/dark theme, responsive)
├── js/script.js          # Theme toggle, mobile menu, scroll effects, carousel
└── assets/
    ├── logo/             # Code.lowa logos, icon and favicon
    └── images/
        ├── portrait.webp, about.webp
        ├── projects/     # Project screenshots
        └── reviews/      # Reviewer photos
```

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Deploy
Upload the whole folder (keep the structure) to GitHub Pages, Netlify or Vercel.
