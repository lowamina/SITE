about

A little about me

I'm a Computer Science undergraduate at the Sri Lanka Institute of Information Technology (SLIIT), with a growing focus on cybersecurity and web development. On the security side, I work with Kali Linux and Arch Linux, using tools like Wifite for wireless security testing and OSINT techniques for reconnaissance and information gathering. On the development side, I build responsive front-ends using Bootstrap and Node.js. I enjoy the balance between offensive security thinking — understanding how systems break — and constructive development — building things that work well and look good. Currently expanding my skill set through coursework, self-study, and hands-on projects, and always open to connecting with others in the tech and infosec community..
